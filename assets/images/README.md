# Images — drop your photos here

The site references the filenames below. Save each photo with the **exact
filename** into this folder (`assets/images/`) and it appears automatically —
no HTML editing needed. Until a file is present, the site shows a labeled
placeholder in its place, so nothing ever looks broken.

Recommended: JPG or WEBP, sized roughly as noted, optimized for web.

| Filename | What goes here | Suggested size |
|---|---|---|
| `larry-portrait.jpg` | **Photo of Larry himself** — the Men's Mental Health Month feature where he's in front of the barber chair. Used in the hero and the "Meet Larry" story section. | ~1000 × 1300 (portrait) |
| `gallery-locs.jpg` | The client with **locs / twists and a clean fade** (side profile, clips in). | ~800 × 1000 |
| `gallery-kids.jpg` | The **young boy with the curly top + fade**. | ~800 × 1000 |
| `gallery-beard.jpg` | The **bald fade with the full sculpted beard** (side profile). | ~800 × 1000 |
| `product-beard-oil.jpg` | The **Beard Oil** bottle from the grooming line. | ~800 × 800 (square) |
| `product-beard-scrub.jpg` | The **Beard Scrub** tin. | ~800 × 800 (square) |
| `product-face-cleanser.jpg` | The **Face Cleanser** tube. | ~800 × 800 (square) |
| `product-face-moisturizer.jpg` | The **Face Moisturizer** tube. | ~800 × 800 (square) |

### Tip: cropping the product shots
Your product photo is one wide lineup. If you want individual product images,
crop the single bottle/tin out for each of the four `product-*.jpg` files. If
you'd rather use the whole lineup shot, you can also just save it once and
point all four product slots at it.
